22  Packages for Epi Work

R has thousands of packages. That number is genuinely overwhelming when you’re starting out, and you don’t need most of it. Real epidemiology work — loading data, cleaning it, summarizing it, mapping it, sharing it — runs on a small, learnable core. This page is that core: a “which package for which job” map, grouped by task, with a pointer to the chapter where the book actually teaches each one.

It’s deliberately short and opinionated. It is not a tour of CRAN. If a package isn’t here, it’s usually because you don’t need it yet — not because it doesn’t exist.

NoteThe tidyverse umbrella

Many of these packages ship together under the tidyverse. One library(tidyverse) call loads readr, dplyr, tidyr, stringr, lubridate, ggplot2, and more all at once. The book loads them individually so it’s always obvious which package a function comes from — but once you know your way around, the umbrella call is a fine shortcut.

22.2 Data manipulation and management — reshaping and cleaning

The everyday workhorses. Most of your time is spent here.

Package What it’s for Where it’s taught

tidyr Reshape between long and wide; pivot, separate, and tidy up Cleaning Data

lubridate Parse and do math with dates and times Cleaning Data
stringr Find, match, and reshape text and character data Cleaning Data
glue Build strings by dropping variables straight into text Cleaning Data

22.3 Data analysis — describing your data

Here’s the honest picture: the book currently does its descriptive work — counts, rates, group summaries — with dplyr::summarise() and friends. That covers a surprising amount of real reporting.

Dedicated statistics packages (for regression, cross-tabulations, age-adjusted rates, survival, and the like) are a future addition to this book rather than something it teaches today. When they arrive, they’ll show up here. For now, dplyr is your analysis engine.

22.5 Reproducible practices and getting data

Pulling data from the web, and turning your analysis into something you can hand off.

Package / Tool What it’s for Where it’s taught
httr2 Talk to web APIs to pull data directly into R Working with APIs and Functions
Quarto Turn code, prose, and results into reproducible reports, sites, and documents This entire book is built with it — see quarto.org

22.6 A note on this list

This is a small core, chosen so you can actually learn it — not a complete inventory. It will grow as the book grows (dedicated stats and table-formatting packages are on the way). When a task isn’t listed here, that’s usually a sign the book hasn’t taught it yet, and inventing a package for it would only add to the overwhelm this page is trying to cut.
