# Project Snapshots

Reference copies of the reader's `covid-briefing/` project, one per chapter,
showing what it looks like as the book progresses. Tracked in git, not
rendered by Quarto (not listed in `_quarto.yml`).

Each `after-ch-NN/` folder is **code only**: `R/`, `scripts/`, and `docs/`
reflect what a reader following along would have written by the end of that
chapter. `data/` and `outputs/` folders are present for structure but stay
empty (`.gitkeep` only) — they're generated by running the scripts, not
duplicated here. This keeps snapshots small and diffable as the book grows.

## Convention

- `after-ch-00/` — state after Ch. 0 (orientation): folder scaffold only, no
  code yet.
- `after-ch-01/` — state after Ch. 1 (working with real data): adds
  `scripts/01_load_and_inspect.R` and `scripts/02_hartford_first_look.R`.
- New chapters add a new `after-ch-NN/` folder, carrying forward the previous
  chapter's scripts plus whatever that chapter introduces.
